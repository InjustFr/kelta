# hello-screen

The smallest useful Kelta screen plugin (PLUGINS.md §4.2, §7).

- `kelta-plugin.toml` declares one screen (`dist/index.html`), a palette command with a keybinding and a
  settings schema (`plugins.hello-screen.greeting`).
- `dist/app.js` uses `dist/kelta-sdk.js`, a vendored copy of `@kelta/plugin-sdk` (regenerated by the SDK
  tests: `KELTA_UPDATE_VENDOR=1 pnpm --filter @kelta/plugin-sdk test`).
- Permissions: `projects.read`, `sessions.read`, `events:session.*`, `notify`, `ui.open` (the command opens
  the screen), `storage` (a visit counter kept with `kelta.kv`). Remove one and the matching call fails with
  `permission_denied`.

The screen runs in `<iframe sandbox="allow-scripts allow-forms">`: no same-origin, no network
(`connect-src 'none'`), no browser storage, no Tauri IPC. Everything goes through the host API.
