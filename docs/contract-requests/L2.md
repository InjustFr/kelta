## Deviations / local workarounds

- Paste helpers (`sanitizePaste`, `needsPasteConfirmation`) live in `ui/src/lib/terminal/paste.ts` (unit-tested) and are used by `view.ts`.
- The initial chunk preloads the scaffold `NotImplemented` stub chunk (19 KB gzip) because lazy pane stubs of other lanes share it; shell plus xterm core stays well under 200 KB gzip (index 27 KB, ui kit 12 KB, xterm 93 KB; the WebGL and search addons load lazily).
- Palette ticket search goes through `tracker_search` with the active project; if the tracker lane returns an error, the section is silently omitted and a single toast is not shown (avoids noise while L-tracker is a stub).
